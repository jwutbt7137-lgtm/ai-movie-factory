## 六、开发中暴露并修复的问题（真实记录）

| 问题 | 现象 | 处理 |
|---|---|---|
| PySceneDetect 合并逻辑错误 | 3 个相邻镜头被合并成 1 个 | 删除“首尾相接即合并”的错误逻辑，仅过滤过短镜头 |
| PySceneDetect 0.7 API 变化 | 回调第二参数为 `FrameTimecode`，旧代码按 int 使用抛 `TypeError` | 增加兼容读法；回调失败后重新打开视频再检测，避免消费已耗尽帧流 |
| FFmpeg 回退阈值偏高 | 低纹理镜头切分漏检 | 默认阈值调整为 0.20；测试素材改为三种静态图案，避免纯色画面 scene 分数异常 |
| faster-whisper + PyAV 19 | `open() got an unexpected keyword argument 'metadata_errors'` | 改传 16kHz float32 NumPy 数组，已在真实模型测试中验证 |
| pip 安装长期无输出 | 卡在 HTTP 缓存临时文件，CPU 空转 | 安装统一加 `--no-cache-dir`；setup 脚本同步修改 |
| SAPI 在 Python 子进程中受限 | `SelectVoice` 报“security setting” | 仓库附带已合成的中文旁白；脚本优先复用；失败则正弦音并明确提示 |
| 测试初始失败（测试代码问题） | 暂停测试先启动线程再暂停；镜头 index 从 0；120.5 秒显示断言错误 | 修正测试同步顺序、index 与时间显示四舍五入规则 |
| pytest 收集范围错误 | 从工作区根目录运行时收集到其他项目测试并 `SystemExit` | 文档明确在项目根目录运行；`pyproject.toml` 固定 `testpaths` |
| 离屏截图中文变方块 | offscreen 平台无字体目录 | 验收截图改用 Windows 原生 Qt 平台；离屏仅用于自动化测试 |

## 九、关键实现验证

- **预算拦截**：调用前按输入 prompt + 输出上限保守估算；预计超预算时客户端抛 `BudgetExceeded`，HTTP 请求不会发出；UI 会先弹确认，用户拒绝则不调用。测试同时覆盖“允许超支”分支。
- **缓存**：相同 model/Base URL/messages/参数/purpose 的请求第二次直接读 SQLite 缓存，不再发 HTTP，费用记 0；失败请求不写入缓存。
- **Key 安全**：401 错误体含伪造 Key 时，异常文本和 API 账目中的错误均不含原文；请求头不进日志。
- **证据校验**：分段事件引用不存在的对白编号时，事件被移除并写警告；部分无效编号会被过滤；整片人物/转折引用不存在分段会被忽略或标记。
- **版本管理**：生成 → v1，重新生成 → v2；人工编辑 → 新版本；旧版本保留；可把 v1 恢复为当前版本。
- **原文与镜头关联**：文案段落保存 `segment_ids`、`evidence_dialogue_ids`、`shot_ids`、`event_descriptions`；第三阶段 TTS 与镜头匹配直接使用这些字段。
- **配音时间轴**：每句真实音频时长 + 停顿累加；完整 WAV 由逐句音频/静音重新混音；缓存按引擎/声音/参数/文本哈希复用。
- **TTS 回退**：主引擎逐句失败时尝试备用引擎；全失败则报错，不生成静音假音频。
- **镜头匹配**：从上一句结束镜头之后推进；候选=段落镜头∪剧情片段镜头；无视觉语义时置信度上限 0.70，全部标记人工审核。
- **UI 后台任务**：AI/TTS/匹配任务使用独立 QThread；支持暂停/取消；主界面不阻塞。

- 本次真实成片使用“烧录+无 BGM”；软字幕/ducking/裁切填充已由自动化测试覆盖，但未做真实播放器兼容性与主观听感验证；
- 导出不支持暂停，只支持取消。
