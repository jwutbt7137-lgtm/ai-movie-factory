# DeepSeek 配置与成本控制

## 1. 配置 API Key

程序**不会**把 Key 写入配置文件、数据库或日志，只读取环境变量。

```bat
set DEEPSEEK_API_KEY=sk-你的Key
run.cmd
```

- 环境变量名可在「设置 → DeepSeek → 密钥环境变量名」中修改。
- 设置后需要重启程序。
- 程序界面只显示“已配置/未配置”，不显示 Key 内容。
- 日志会对 `sk-...`、`Bearer ...`、`api_key=...` 形式做脱敏。

推荐用系统“用户环境变量”而不是把 Key 写进 `run.cmd`，避免误提交到代码仓库。

## 2. 可配置项

| 配置 | 位置 | 默认 | 说明 |
|---|---|---|---|
| 接口地址 | 设置 → DeepSeek | `https://api.deepseek.com` | 兼容 OpenAI Chat Completions |
| 文本模型 | 设置 → DeepSeek | `deepseek-chat` | 可改为账号可用模型 |
| 超时 | 设置 → DeepSeek | 120 秒 | 单次 HTTP 超时 |
| 重试次数 | 设置 → DeepSeek | 2 | 429/5xx/网络错误重试 |
| 重试退避 | 设置 → AI 生成 | 1 秒 | 指数退避基数 |
| 输入/输出单价 | 设置 → DeepSeek | 2 / 8 元每百万 tokens | 仅用于本机估算，可按最新价格修改 |
| 单项目预算 | 设置 → DeepSeek | 5 元 | 0 表示不限制 |
| 缓存 | 设置 → AI 生成 | 开启 | 相同请求不重复计费 |
| 分段字符数 | 设置 → AI 生成 | 4500 | 影响调用次数与上下文长度 |
| 解说语速 | 设置 → AI 生成 | 240 字/分钟 | 用于目标字数 |

## 3. 费用如何计算

- 成功调用：优先使用接口返回的 `usage.prompt_tokens / completion_tokens`；
- 缺少 usage：按中文字符保守估算，并在账目中标记“估算”；
- 费用 = 输入 tokens / 1,000,000 × 输入单价 + 输出 tokens / 1,000,000 × 输出单价；
- 缓存命中：不发起 HTTP，费用记 0；
- 失败调用：记一条费用 0 的失败账目（含错误摘要），便于排查；
- 实际账单以 DeepSeek 账单为准；本机费用是估算/对账辅助，不是付款凭证。

## 4. 预算拦截流程

1. 启动剧情分析/文案生成前，用 prompt 字符 + 输出上限做保守预检。
2. 如果 `已用 + 预计 > 预算`：
   - GUI：弹窗显示预计/已用/预算，用户选“否”则不发请求；选“是”则允许本次任务超支。
   - CLI：默认停止并提示；确认后加 `--allow-over-budget`。
3. 客户端每次真实调用前再次检查项目已用费用；未获确认不会发送。
4. 预算上限为 0 表示不限制（仍会记录真实费用）。
5. 任务中断/失败后重新运行：相同请求命中缓存，不会重复计费。

## 5. 缓存与隐私

- 缓存键包含 Base URL、模型、用途、messages、temperature、max_tokens。
- 缓存保存在 `data/app.db` 的 `llm_cache` 表；响应用于本机重放，不上传。
- 发送给 DeepSeek 的内容仅限：对白文本、时间码、镜头编号、提示词。
- **不发送**：影片文件、关键帧图片、本机路径、API Key 之外的凭据。
- 请求/响应正文不写入运行日志。

## 6. 首次真实调用建议

1. 用 3–5 分钟短片或有对白的测试片段。
2. 在设置中把单项目预算设为 1–2 元，模型先用 `deepseek-chat`。
3. 先跑 `story`，检查费用页 Token/费用与 DeepSeek 控制台是否一致。
4. 再跑 `script`，检查文案事实、原创性和平台合规。
5. 确认提示词与成本符合预期后，再处理长片；长片会增加分段调用次数。
